# Inter 4.1 — ImobFlow Linha

Unmodified variable font from the Inter Project, self-hosted to avoid external
font requests at runtime. It covers the Portuguese interface and weights 100–900.

- Author: The Inter Project Authors, https://github.com/rsms/inter
- Source: https://rsms.me/inter/font-files/InterVariable.woff2?v=4.1
- Retrieved: 2026-10-09
- SHA-256: `693b77d4f32ee9b8bfc995589b5fad5e99adf2832738661f5402f9978429a8e3`
- License: SIL Open Font License 1.1, reproduced in `OFL.txt`.

The interface uses `--crm-font`; no external CDN is required during page loads.
